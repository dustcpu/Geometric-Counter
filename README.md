> 一片住在 Win11 任务栏左侧空白区的小海：你打字，几何体就从水里浮出来。

本仓库是**去除作者隐私信息**后的开源版本——程序、完整可编译源码、出包脚本一并给出，可直接拿去编译、改造或分发给朋友。

- **只想用** → 到 [Releases](https://github.com/dustcpu/Geometric-Counter/releases) 下载安装程序或免安装包，看第二节
- **想看 / 改代码** → 源码在 `源码/`，编译方法见 `源码/README.md`

## 更新日志

### v0.1.0（2026-09-18）首次预览版

**新增**
- **自适应布局**：自动测量任务栏的开始按钮与托盘位置来摆放卡片，不同分辨率 / 缩放下都不会压住图标
- **分辨率、DPI、图标数量变化自动重定位**：改缩放、换屏幕、任务栏图标增减都不用重启程序
- **打字进度双写**：`localStorage` + `%LOCALAPPDATA%\GeometricCounter\stats.json`，可查看、可备份、可搬到别的电脑
- **让位机制**：点开始菜单 / 悬停任务栏图标弹出预览时海面自动隐藏，关闭后自动回来
- **蓄能发光**：连打把几何体喂到体型上限后不再撑出卡片，改为持续发光，停手约 1.4 秒回落
- **悬停高亮**：鼠标移到海面卡上，描边常亮 + 边缘内发光
- **主循环兜底**：单帧异常只丢一帧，不会再让整片海卡死
- **单实例锁**：重复双击启动脚本只会有一片海
- 安装程序：免管理员、中文界面、开始菜单 + 桌面快捷方式、可在「应用」里卸载

**优化**
- 波浪线与水面线两端渐隐溶解，与卡片圆角自然衔接（不再是硬切）
- 任务栏被点击时的闪烁：由 300 ms 轮询升级为**事件级抢层**（`SetWinEventHook`），毫秒级抢回
- release 编译（8.5 MB，无调试开销，CPU / 内存占用更低）
- 卡片描边随击键轻微呼吸，与海里的几何体节奏一致

**修复与适配**
- 全局打字的信号通道有一处校验错误（表现：某些机器上完全没反应）
- 「满槽收拢」注入成长没有上限，导致几何体撑出卡片
- 悬停判定误覆盖到中间图标区（现在只认左侧海面卡）
- 删除右侧卡片元素后高亮循环仍引用它，导致一打字界面就卡死
- 源码与二进制里作者本机的路径、用户名、账号标识全部清除

## 一、这是什么

一片浮在 **Win11 任务栏左侧空白区**上的小海：

- 你在**任何窗口打字**（浏览器、微信、Word…）→ 海面会有几何体破水浮出
- 任务栏**右侧空白处**会飘落季节粒子（九月是银杏叶，随季节与昼夜切换）
- 累计打字次数会解锁**成就徽章**，最终能解锁会自转的彭罗斯三角
- 它**不修改任务栏本身**，只是一个置顶小窗口；**不联网、不上传**

> 它**不是壁纸**：不改注册表、不替换桌面背景、不铺满屏幕——只是任务栏上一条 48 像素高的卡片。

## 二、下载与安装

### 从 GitHub 取

[Releases](https://github.com/dustcpu/Geometric-Counter/releases) 页面有两个文件：

| 文件 | 说明 |
|---|---|
| `几何任务栏小插件-setup-*.exe` | **安装版**（约 1.8 MB）：双击 → 下一步 → 完成 |
| `几何任务栏小插件-share-*.zip` | **免安装版**：解压 → 双击 `启动-几何任务栏小插件.bat` |

### 安装版（推荐）

1. 双击 setup
   - 若弹 SmartScreen「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」（预览版没有数字签名）
   - 一路「下一步」→ 最后可选「立即启动」
2. 桌面 / 开始菜单出现**快捷方式**，以后双击它即可
3. 安装**不需要管理员权限**（装在 `%LOCALAPPDATA%\GeometricCounter`）

### 免安装版

1. 解压 zip 到任意位置
2. 双击 **`启动-几何任务栏小插件.bat`**
3. 不想要了 → 双击 `退出-几何任务栏小插件.bat` → 整个文件夹删掉

### 启动后应该看到

任务栏**左侧**出现一条深色圆角卡片，上面有淡蓝色波浪线在起伏。鼠标移到卡片上 → 卡片描边亮起。

## 三、怎么退出

| 方式 | 说明 |
|---|---|
| `Ctrl + Shift + Q` | 最快，任何窗口下都有效 |
| 托盘图标「蓝色方块」右键 → 退出 | 蓝色方块默认被 Windows 藏在任务栏右下角的 **`∧`** 里，可以拖出来固定 |
| 双击 `退出-几何任务栏小插件.bat`（免安装版） | 前两者都失灵时的兜底 |

## 四、数据存在哪（想备份的话）

累计打字次数存在两个地方，互为备份：

- 程序内部（WebView2 数据目录）
- **JSON 文件**：`%LOCALAPPDATA%\GeometricCounter\stats.json`
  （地址栏粘贴 `%LOCALAPPDATA%\GeometricCounter` 即可打开）

删掉这个文件不会出错，只是计数回到 0；想让两台电脑进度一致，把文件拷过去覆盖即可。

> 从改名前的测试版升级上来的话，旧目录 `GeometricOceanWallpaper` 里的进度会在首次启动时自动读过来，不用手动搬。

## 五、卸载

- **安装版**：设置 → 应用 → 「几何任务栏小插件」→ 卸载
  （自动结束进程、删程序与快捷方式、清注册表登记）
- **免安装版**：先双击退出脚本，再删掉整个文件夹

> **卸载后保留的东西**：只有 `%LOCALAPPDATA%\GeometricCounter\stats.json`（你的打字进度）。
> 这是有意的——想彻底清干净，把那个文件夹一起删掉即可。

## 八、隐私说明（请放心）

- **不联网、不上传任何数据**
- 全局键盘监听收到按键后，**立刻**把它归成六个「区域」之一
  （左手区 / 右手区 / 空格区 / 数字区 / 功能键区 / 编辑键区）然后丢弃——
  **你按了哪个键，程序从头到尾都不知道**，不记录、不保存、不外传
- 打字统计只存在你自己电脑上
- 源码和二进制里作者的**用户名、本机路径、账号标识已全部清除**
  （编译器路径重写 + 打包时逐项扫描），拿到包可以自行核对
